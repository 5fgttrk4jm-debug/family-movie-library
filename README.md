# Family Movie Library

GitHub Pages-ready static catalog. Upload `index.html` and `catalog.json` to the repository root. Enable Pages from the main branch.

**Important:** 320 provisional entries. Not reconciled against the full photographed collection. Poster URLs are blank until individually verified. `catalog.json` is the editable source data for future iterations; the current standalone `index.html` has the same entries embedded to support iPhone preview. Changes to JSON require regenerating HTML.

The website is publicly accessible even though search engines are asked not to index it.
