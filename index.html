    iPhone: save the file and send it in Messages

    Shortcut: if “Share .md file” is shown, tap it and choose Messages. Pick your recipient and tap Send. To keep a copy first, choose Save to Files instead.

    1. Tap Save .md file. If Safari asks, tap Download.
    2. Open Files → Browse → iCloud Drive → Downloads (or On My iPhone → Downloads). If you can’t find it, check Safari’s Downloads button.
    3. Touch and hold the movie-picks…md file, then tap Share → Messages.
    4. Choose your recipient and tap Send. For iMessage, check that the conversation uses blue bubbles.

    The .md file is a plain-text Markdown checklist. You don’t need a special app to send it.
